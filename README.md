# Briefd

A pure static site. No build step, no dependencies.

## Structure

```
briefd/
  index.html   — entry point
  style.css    — styles
  app.js       — client-side logic
  README.md    — this file
```

## Running locally

Open `index.html` directly in a browser, or serve with any static file server:

```sh
npx serve .
# or
python -m http.server
```
